# Anesthesia study dashboard

Static version of a MotherDuck Dive. The data is dummy data, exported once to
`public/data/anesthesia.duckdb`, and the queries run in the browser with DuckDB-WASM.
No token or server is needed.

- Live page: https://adaydan-tabsdata.github.io/anesthesia-study-dashboard/
- Build: `npm install && npm run build` (writes to `docs/`)
- Dev: `npm run dev`
